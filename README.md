(Набережночелнинский проспект, 23а, 2 этаж, Комсомольский район).

- Данные: карточка [2ГИС](https://2gis.ru/nabchelny/firm/70000001082965391) —

- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01/02/03/04/05
